# Roadmap recommandee

## V1.0 - Prototype interne

- Application FastAPI locale.
- Adresse vers coordonnees.
- Equipements OSM dans 500 m.
- Dechets OSM dans 3 km.
- Rapport HTML/XML.

## V1.1 - Consolidation risques et PDF serveur

- Remplacer les appels Georisques best-effort par endpoints valides et normalises.
- Ajouter generation PDF serveur avec Playwright.
- Ajouter tests automatiques.
- Ajouter cache API.

## V1.2 - Cadastre

- Recherche parcelle par adresse ou reference cadastrale.
- Affichage geometrie parcelle sur carte.
- Surface parcelle si disponible.

## V2 - Donnees environnementales avancees

- Bruit dB officiel.
- Natura 2000, ZNIEFF, patrimoine.
- TVB/SRCE par region.
- Geologie BRGM.
- Eaux souterraines.
- PLU et servitudes.

## V3 - Produit interne complet

- Authentification.
- Historique rapports.
- Comparaison multi-sites.
- Scoring foncier.
- Exports Excel, XML enrichi, GeoJSON.
